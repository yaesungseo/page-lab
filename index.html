About this experiment

This viewer replays events exported from a C virtual-memory simulator extended from a CS2200 course project. Every frame state and replacement decision comes from the engine, not a browser-side algorithm.

Each page is 16 KiB. Two of the five active physical frames hold system structures; three hold data. This fixed demo repeatedly accesses five virtual pages at byte offset 8.

Free frames are used first. When memory is full, Clock Sweep scans from the frame after the last eviction. It clears R=1 bits and replaces the first page with R=0. The accessed page ends with R=1.

AMAT = (accesses × 200 + faults × 150,000 + writebacks × 250,000) ÷ accesses. This course model charges a fault cost even for first-time allocation. Values are simulated costs, not measured hardware latency.
