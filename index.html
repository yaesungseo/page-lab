About this experiment

This viewer replays events exported from a C virtual-memory simulator extended from a CS2200 course project. Every frame state and replacement decision comes from the engine, not a browser-side algorithm.

Each page is 16 KiB. Two of the five active physical frames hold system structures; three hold data. This fixed demo repeatedly accesses five virtual pages at byte offset 8.

Free frames are used first. When memory is full, Clock Sweep scans from the frame after the last eviction. It clears R=1 bits and replaces the first page with R=0. The accessed page ends with R=1.

AMAT = (accesses × 200 + faults × 150,000 + writebacks × 250,000) ÷ accesses. This course model charges a fault cost even for first-time allocation. Values are simulated costs, not measured hardware latency.

Approximate LRU chooses the lowest 8-bit aging counter, breaking ties by frame order. Before every fifth access, the daemon shifts counters right, inserts the previous R bit into the high bit, and clears R. The “before” snapshot is after this update.

Random is the course-provided baseline: it visits eligible frames in order, accepting each on an odd PRNG result, with the last eligible frame as fallback. It is not uniform sampling. The PRNG starts from the same fixed state for each engine run.

Approximate LRU and Clock Sweep are the original student implementations. Event instrumentation and this comparison interface are Codex-assisted extensions. All policies use the exact same 20-access trace and frame budget; this small illustrative workload does not establish a general ranking.
